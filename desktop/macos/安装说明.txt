PKUNMUN 2026 文件排版系统 · macOS 本机离线版

【安装】
把「PKUNMUN 2026 文件排版系统」拖到旁边的「Applications」（应用程序）文件夹，就装好了。
适用于 macOS 10.11 及以上，Intel 与 Apple 芯片的 Mac 都可以直接运行，不需要安装 Rosetta。

【打开】
在「应用程序」或启动台里双击它。
已安装 Chrome、Edge、Brave 或 Vivaldi 时，会打开一个独立的程序窗口；否则用 Safari 打开（Safari 版本太旧时用 Firefox）。

【第一次打开时被拦住？】
本程序没有付费的 Apple 开发者签名，macOS 第一次会提示“无法验证开发者”或“Apple 无法检查其是否包含恶意软件”。
这不代表文件有问题，按下面做一次即可，以后正常双击打开：
  · macOS 15 及以后：先双击一次并点「完成」，然后打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」，输入开机密码确认。
  · macOS 14 及以前：在「应用程序」里按住 Control 键点按它，选「打开」，再点「打开」。

【不想改任何设置？】
双击本窗口里的「直接用浏览器打开.html」。它只是一个网页，会用你的默认浏览器打开同一个排版页面，不运行任何程序，所以不需要授权。
想以后也这样用：先把程序拖进「应用程序」，再把「直接用浏览器打开.html」拖到桌面，以后双击它即可。

【浏览器版本】
需要 Safari 15.4、Chrome / Edge 99 或 Firefox 104 及以上。
macOS 10.11–10.14 的 Safari 版本不够，请安装 Chrome 或 Firefox。浏览器过旧时页面会直接说明。

【纯本机】
  · DOCX 只在你的电脑上处理，程序不联网、不上传任何内容（页面的安全策略禁止一切网络连接）。
  · 不需要安装 Python 或其他运行环境，也不会在后台常驻。
  · 生成的 DOCX 保存在「下载」文件夹。

【卸载】
把「应用程序」里的它拖到废纸篓即可。
