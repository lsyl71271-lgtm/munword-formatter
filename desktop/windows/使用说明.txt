PKUNMUN 2026 文件排版系统 · Windows 本机离线版

【打开】
双击桌面或开始菜单里的「PKUNMUN 2026 文件排版系统」。
程序优先使用你的默认浏览器（Edge、Chrome、Brave、Vivaldi 或 Firefox），否则依次查找这几个浏览器。
Edge、Chrome、Brave、Vivaldi 会打开一个独立窗口，Firefox 会打开一个新窗口。

【使用】
选择文件类型 → 上传原稿 → 确认识别 → 生成下载。
生成的 DOCX 保存在「下载」文件夹。

【适用系统与浏览器】
  · Windows 7、8.1、10、11，32 位和 64 位都可以，ARM 电脑也可以。
  · 需要 Edge / Chrome 99 或 Firefox 104 及以上。Windows 10 / 11 自带的 Edge 即可。
  · Windows 7 / 8.1：请使用 Chrome 109 或 Firefox ESR 115（这两个系统上能装的最后版本）。
  · 只有 IE 或浏览器太旧时，页面会说明该安装哪个浏览器，不会白屏。

【纯本机】
  · DOCX 只在你的电脑上处理，程序不联网、不上传任何内容（页面的安全策略禁止一切网络连接）。
  · 不需要管理员权限，也不需要 Python 等运行环境，不会在后台常驻。

【安装时提示“Windows 已保护你的电脑”？】
安装程序没有付费的代码签名证书，SmartScreen 会提示一次。点「更多信息」→「仍要运行」即可。

【更新】
直接运行新版本的安装程序，会覆盖旧版本。

【卸载】
「设置 → 应用 → 安装的应用」中找到「PKUNMUN 2026 文件排版系统」，点「卸载」。
Windows 7 / 8.1：「控制面板 → 程序和功能」。
