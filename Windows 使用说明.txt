PKUNMUN 2026 文件自动排版系统（Windows 本机版）

适用：Windows 10 / 11。文件只在自己的电脑上处理，不会上传到云端。

一、准备 Python（只需一次）
1. 打开 https://www.python.org/downloads/windows/ ，下载并安装 Python 3（3.9 或更高版本都可以）。
2. 安装界面第一页务必勾选“Add python.exe to PATH”，再点 Install Now。
   已经装过 Python 的电脑可以跳过这一步。

二、首次安装
1. 右键下载的压缩包 →“全部解压缩”。不要在压缩包里直接双击运行。
2. 打开解压后的文件夹，双击“Windows 首次安装.bat”。
   - 如果出现“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 窗口会显示安装进度。第一次需要联网下载运行组件，约 1–3 分钟；
   默认下载源连不上时会自动改用清华大学镜像。
4. 完成后浏览器会自动打开排版页面，桌面上会出现“PKUNMUN 2026 文件排版系统”图标。

三、日常使用
- 双击桌面上的“PKUNMUN 2026 文件排版系统”即可打开页面（地址 http://127.0.0.1:8000）。
- 选择文件类型，上传 DOCX，确认第 03 步识别结果，再生成并下载。
- 页面上提示“请双击应用图标”时，指的就是这个桌面图标。
- 排版引擎在后台运行，关闭浏览器不影响。要停止它：开始菜单 → PKUNMUN 2026 → 停止排版引擎。
  与 macOS 版不同，Windows 版不会开机自动启动，双击图标时才启动。

四、更新
解压新版本压缩包，再双击一次其中的“Windows 首次安装.bat”即可。旧版本会自动停止并被替换。

五、常见问题
- 提示“未找到可用的 Python”：按第一部分安装 Python，并确认勾选了“Add python.exe to PATH”。
  安装后需要重新双击安装程序。
- 提示“端口 8000 已被其他程序占用”：通常是开发服务器等程序占用了 8000 端口，退出该程序后再打开。
- 提示“排版引擎未能启动”：把提示中的日志文件
  %LOCALAPPDATA%\PKUNMUN2026Formatter\backend.log 发给维护者。
- 下载组件失败：检查网络后重新运行安装程序；仍然失败时，可以改装 Python 3.12 或 3.13 再试。

六、卸载
开始菜单 → PKUNMUN 2026 → 卸载。会删除 %LOCALAPPDATA%\PKUNMUN2026Formatter 和快捷方式，
不会动你自己的 DOCX 文件。解压出来的文件夹可以直接删除。
