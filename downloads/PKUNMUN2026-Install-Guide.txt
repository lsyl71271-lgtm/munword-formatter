==============================================================
  PKUNMUN 2026 文件排版系统 · 安装与使用教程（手把手版）
  版本 2.0.0    适用于：苹果电脑（macOS）、Windows 电脑、安卓手机、网页版
==============================================================

把格式凌乱的模联文书交给它，几秒钟拿到排版规范、可以继续编辑的 Word（DOCX）文件。
支持立场文件、工作文件、指令草案、决议草案、友好修正案、非友好修正案、外交协定、联合声明，
中英文都可以。
所有处理都在你自己的电脑或手机上完成，文件不会上传到任何地方。

本教程目录
  一、先选一种用法（30 秒看懂）
  二、苹果电脑安装（含弹窗处理）
  三、Windows 电脑安装（含弹窗处理）
  四、安卓手机安装（含弹窗处理）
  五、怎么使用（四步）
  六、系统或浏览器太旧怎么办
  七、常见问题

一、先选一种用法（30 秒看懂）
--------------------------------------------------------------

  ● 网页版：什么都不用装
      打开这个网址即可使用：https://munword-formatter.pages.dev/
      适合临时用一下，或者在别人的电脑上用。

  ● 苹果电脑版 / Windows 版 / 安卓版：装一次，以后断网也能用
      下载页：https://github.com/lsyl71271-lgtm/munword-formatter/releases/latest
      打开下载页后往下翻，找到「Assets」，点文件名下载：

        苹果电脑  →  PKUNMUN2026-Formatter-macOS.dmg          （约 0.8 MB）
        Windows   →  PKUNMUN2026-Formatter-Windows-Setup.exe  （约 0.5 MB）
        安卓手机  →  PKUNMUN2026-Formatter-Android.apk        （约 0.4 MB）

      PKUNMUN2026-Install-Guide.txt 就是这份教程；其他文件（SHA256SUMS.txt、Verification.zip）不用下载。

  不知道自己是哪种电脑？
      屏幕左上角有苹果标志  → 苹果电脑，看第二部分
      屏幕左下角有 Windows 徽标（开始按钮）→ Windows 电脑，看第三部分
      安卓手机（华为、荣耀、小米、OPPO、vivo、三星等）→ 看第四部分
      苹果手机（iPhone、iPad）→ 没有安装包，用网页版

  下载页打不开或很慢？
      先用网页版；或者请同学把安装文件直接发给你，效果完全一样。

二、苹果电脑（macOS）安装
--------------------------------------------------------------

适用：macOS 10.11 及以上。
Intel 芯片和 Apple 芯片（M1、M2、M3、M4……）用的是同一个文件，不用分。

【第 1 步】下载
  下载 PKUNMUN2026-Formatter-macOS.dmg，它一般在「下载」文件夹里。

【第 2 步】打开安装窗口
  双击这个 .dmg 文件，会弹出一个窗口：
    左边是程序图标「PKUNMUN 2026 文件排版系统」
    右边是「Applications」（应用程序）文件夹

【第 3 步】拖进去就装好了
  用鼠标按住左边的程序图标，拖到右边的「Applications」上，松手。
  等一两秒复制完，就安装好了。

【第 4 步】打开程序
  打开「访达 → 应用程序」（也可以在启动台里找），双击「PKUNMUN 2026 文件排版系统」。

  第一次打开会被系统拦一下，这是正常现象，请看下面的「弹窗处理」。
  只需要处理这一次，以后双击就能直接打开。

  打开后会发生什么：
    装了 Chrome、Edge、Brave 或 Vivaldi：弹出一个独立的程序窗口。
    都没装：用 Safari 打开（Safari 太旧时改用 Firefox）。

【第 5 步（可选）】收起安装盘
  装好后，桌面上会留着一个叫「PKUNMUN 2026」的磁盘图标。
  右键点它，选「推出」即可。下载的 .dmg 文件也可以删掉。


■ 苹果电脑弹窗处理
  本程序没有向苹果购买付费的开发者认证，所以第一次打开时 macOS 会拦一下。
  这不代表文件有问题。根据你的系统版本，选下面一种办法。
  （查看系统版本：点左上角苹果标志 → 关于本机）

  ▶ 情况 A：macOS 15 及更新的系统
    弹窗大意是「未打开“PKUNMUN 2026 文件排版系统”」「Apple 无法验证……」：
      1. 点「完成」。千万不要点「移到废纸篓」。
      2. 马上点左上角苹果标志 → 「系统设置」 → 左边点「隐私与安全性」。
      3. 右边往下翻到「安全性」，会看到一行提示，说本程序已被阻止。
         点这行提示旁边的「仍要打开」。
      4. 输入开机密码，或者按一下指纹。
      5. 如果再弹出确认框，点「仍要打开」或「打开」。
    完成。以后双击就能直接打开。
    小提示：要在第 1 步之后马上去设置里找。隔太久「仍要打开」按钮可能会消失，
            这时回去再双击一次程序，按钮就会重新出现。

  ▶ 情况 B：macOS 14 及更早的系统
    弹窗大意是「无法打开……因为无法验证开发者」或「Apple 无法检查其是否包含恶意软件」：
      1. 点「好」或「取消」，关掉弹窗。
      2. 打开「访达 → 应用程序」，找到「PKUNMUN 2026 文件排版系统」。
      3. 按住键盘上的 Control 键，再点一下程序图标（或者用触控板双指点按）。
      4. 在弹出的菜单里选「打开」。
      5. 弹窗里再点一次「打开」。
    完成。以后双击就能直接打开。
    如果弹窗里没有「打开」按钮：
      进「系统设置 → 隐私与安全性」（老系统是「系统偏好设置 → 安全性与隐私 → 通用」），
      点里面的「仍要打开」。

  ▶ 情况 C：一个设置都不想改（最省事，推荐）
    双击安装窗口里的「直接用浏览器打开.html」。
    它就是完整的排版页面，会用你的浏览器打开，不运行任何程序，所以不需要任何授权，
    甚至不用先安装。
    想以后都这么用：把「直接用浏览器打开.html」拖到桌面，以后双击桌面上的它就行。

  ▶ 提示「已损坏，无法打开」
    正常下载的文件不会出现这个提示。如果出现了，多半是下载不完整：
      先把它删掉，再从下载页重新下载；或者直接用上面的情况 C。
    （懂电脑的同学可以在「终端」里运行下面这行，然后再打开程序：
        xattr -dr com.apple.quarantine /Applications/PKUNMUN2026.app  ）

  ▶ 浏览器问「是否允许下载」
    生成文件时，如果浏览器问是否允许下载，点「允许」。

三、Windows 电脑安装
--------------------------------------------------------------

适用：Windows 7、8.1、10、11。
32 位、64 位和 ARM 电脑都用同一个安装包，不用分。
不需要管理员权限。

【第 1 步】下载
  下载 PKUNMUN2026-Formatter-Windows-Setup.exe。
  如果浏览器拦住了下载：
    Edge：把鼠标移到下载记录上，点「…」→「保留」；
          如果还有提示，点「显示更多」→「仍然保留」。
    Chrome：点「保留」。

【第 2 步】运行安装包
  双击下载好的 .exe 文件。
  如果弹出蓝色窗口「Windows 已保护你的电脑」：
    1. 点窗口里的「更多信息」（一行小字）。
    2. 点出现的「仍要运行」按钮。
  如果 360、火绒、腾讯电脑管家等软件提示风险：选「允许」或「信任此程序」。
  （原因：安装包没有购买付费的代码签名证书，不代表有问题。）

【第 3 步】安装
  在安装窗口里点「安装」，几秒钟就好，安装位置不用选。

【第 4 步】完成
  最后一页默认勾选了「立即打开 PKUNMUN 2026 文件排版系统」，点「完成」就会打开。
  以后：双击桌面上的「PKUNMUN 2026 文件排版系统」，或者在开始菜单里找到它。

  打开后会发生什么：
    优先用你的默认浏览器。Edge、Chrome、Brave、Vivaldi 会打开一个独立窗口，
    Firefox 会打开一个新窗口。
    Windows 10 / 11 自带的 Edge 就可以用，不用另外装浏览器。

  安装位置（一般不用管）：
    C:\Users\你的用户名\AppData\Local\Programs\PKUNMUN2026Formatter

【更新】直接运行新版本的安装包，会自动覆盖旧版本。
【卸载】Windows 10 / 11：设置 → 应用 → 安装的应用 → 找到「PKUNMUN 2026 文件排版系统」→ 卸载。
        Windows 7 / 8.1：控制面板 → 程序和功能 → 找到它 → 卸载。


■ Windows 弹窗处理
  ▶「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（见第 2 步）。
  ▶ 杀毒软件拦截 → 选「允许」或「信任」。
  ▶ 打开时提示「没有找到可用的浏览器……」
      说明电脑上没有能用的浏览器，或者版本太旧。按第五部分安装或更新 Edge / Chrome，再打开。
  ▶ 打开时提示「程序文件不完整，请重新运行安装程序」
      再运行一次安装包即可。
  ▶ 安装时提示「安装位置的路径太长」
      极少出现（一般是 Windows 用户名特别长）。遇到时直接用网页版即可，效果完全一样。

四、安卓手机（Android）安装
--------------------------------------------------------------

适用：Android 5.0 及以上的手机和平板。
华为、荣耀、小米、OPPO、vivo、三星等品牌都可以装。
鸿蒙 HarmonyOS NEXT（鸿蒙 5 及以后的新系统，俗称「纯血鸿蒙」）不能安装安卓应用，请用网页版。
苹果手机（iPhone、iPad）没有安装包，请用网页版。

【第 1 步】下载
  用手机浏览器打开下载页，在「Assets」里点 PKUNMUN2026-Formatter-Android.apk（约 0.4 MB）。
  在微信里打开下载页时，微信不能直接下载安装包：点右上角「…」→「在浏览器打开」，再下载。
  也可以请同学把 APK 文件直接发给你，在微信、QQ 里收到后点开即可。

【第 2 步】安装
  点下载好的文件（在浏览器的下载记录里，或「文件管理 → 下载」里）。
  第一次安装这类文件时，手机会提示「已禁止安装未知来源的应用」之类：
    点「设置」，打开「允许来自此来源的应用」（或「允许安装未知应用」），返回后点「安装」。
  部分手机还会再提示一次：
    华为 / 荣耀：「纯净模式」拦截 → 点「仍然安装」（或暂时退出纯净模式，装好再打开）。
    小米 / 红米：「风险提示」→ 勾选「已了解此应用未经安全检测」，点「继续安装」。
    OPPO / 一加 / vivo：可能要输入账号密码，或等几秒安全检测 → 按提示「继续安装」。
  （原因：本应用没有上架应用商店，也没有付费的安全认证，不代表有问题。
    它没有联网权限，什么也不会发送出去。）

【第 3 步】打开
  桌面上出现「PKUNMUN 排版」图标，点开就是和网页版一样的排版页面，完全离线可用。

【手机上的用法】
  ● 在应用里点上传框，选手机里的 Word 文件（.docx）。
  ● 或者在微信 / QQ / 文件管理里打开 DOCX 文件 →「用其他应用打开」→ 选「PKUNMUN 排版」，
    文件会直接放进上传框，再点选文书类型即可（文件会保留，不用重新选）。
  ● 生成后，成品保存在手机的「下载」（Download）文件夹，屏幕上会弹出提示：
      点「打开」：用 WPS 或 Microsoft Word 查看（没有的话先在应用商店安装 WPS Office）；
      点「分享」：发到微信、QQ、邮箱等。
  ● Android 6 – 9 的手机第一次保存时会询问存储权限，请点「允许」。
    如果点了拒绝，文件会保存在应用自己的文件夹里，同样可以点「打开」「分享」。
  ● 按返回键会回到桌面，再点图标回来，刚才的进度还在。

【更新】安装新版本的 APK 会直接覆盖旧版本，不用先卸载。
【卸载】长按桌面图标 → 卸载（或 设置 → 应用 → PKUNMUN 排版 → 卸载）。


■ 安卓弹窗与提示
  ▶ 打开后显示「手机的网页组件（WebView）版本太旧」
      按第六部分「安卓手机」更新 WebView。
  ▶ 微信里点 APK 没反应
      微信不能直接安装应用：点右上角「…」→「用其他应用打开」→ 选「文件管理」或「安装器」。
  ▶ 提示「解析软件包时出现问题」
      多半是没下载完整，请重新下载；系统低于 Android 5.0 也会这样（不支持）。

五、怎么使用（四步）
--------------------------------------------------------------

  01 选择类型：点选你的文书类型（立场文件、决议草案、外交协定、联合声明等）。
  02 上传原稿：把 Word 文件（.docx，最大 20 MB）拖进框里，或者点「浏览本地文件」。
               然后点「识别文件结构」。
  03 确认识别：检查系统识别出的标题、国家、条款等。不对的地方可以直接在这里改。
  04 生成下载：点「生成并下载 DOCX」，文件会保存到电脑的「下载」文件夹。
               点「查看实际 DOCX 页面」，可以对比原稿和成品的样子。
               决议草案的成品沿用你上传的文件名，不用再填会期、国家和版本号。

  外交协定和联合声明：程序从标题读出签署方（几方就是几方），第三步只需确认语言和签署方。
  签字栏按签署方补齐「XX代表」，每行最多三方；原稿写好的代表和姓名保留，没写的姓名留空供签字。

  没有原稿？点「从规范模板新建文件」，按提示填写内容，直接生成规范文件。
  在手机上：生成的文件在手机的「下载」文件夹，详见第四部分。

六、系统或浏览器太旧怎么办
--------------------------------------------------------------

如果打开后页面显示「这个浏览器版本太旧，无法运行排版系统」，按下面更新即可。

【最低要求】
  Edge 99、Chrome 99、Firefox 104、Safari 15.4 或更新的版本。
  IE 浏览器不能用。

【怎么更新浏览器】（复制下面的网址，粘贴到浏览器地址栏，按回车）
  Edge   ：edge://settings/help    → 自动检查并更新 → 点「重启」
  Chrome ：chrome://settings/help  → 自动检查并更新 → 点「重新启动」
  Firefox：右上角菜单（三条横线）→ 帮助 → 关于 Firefox → 自动更新 → 重启
  Safari ：跟随系统一起更新（见下面「苹果电脑」）

【没有合适的浏览器？下载一个】
  Edge   ：https://www.microsoft.com/zh-cn/edge
  Chrome ：https://www.google.cn/chrome/
  Firefox：https://www.mozilla.org/zh-CN/firefox/

【Windows 电脑】
  查看系统版本：按键盘上的 Windows 键 + R，输入 winver，按回车。
  ● Windows 10 / 11：自带的 Edge 更新到最新就能用。
      Windows 更新（设置 → Windows 更新）也会顺带更新 Edge。
  ● Windows 7 / 8.1：这两个系统上 Edge 和 Chrome 最高只能到 109 版，Firefox 最高到 ESR 115 版。
      这些版本都够用，更新到这一版即可。浏览器会提示「不再支持此系统」，不影响使用。
  ● Windows XP / Vista：不支持。请换一台 Windows 7 或更新的电脑，或者在其他设备上用网页版。

【苹果电脑】
  查看系统版本：点左上角苹果标志 → 关于本机。
  ● 怎么更新系统和 Safari：
      macOS 13 及更新：苹果标志 → 系统设置 → 通用 → 软件更新
      macOS 10.14 – 12：苹果标志 → 系统偏好设置 → 软件更新
      macOS 10.13 及更早：打开 App Store → 更新
  ● macOS 10.15 及更新：把系统或 Safari 更新到最新，Safari 就够用了（15.4 以上）。
      也可以直接安装 Chrome 或 Edge。
  ● macOS 10.11 – 10.14：系统自带的 Safari 升级不到 15.4，请安装 Chrome 或 Firefox：
      macOS 10.13 / 10.14：Chrome（最高 116 版）或 Firefox（最高 ESR 115 版）都可以。
      macOS 10.12：Chrome（最高 103 版）或 Firefox（最高 ESR 115 版）都可以。
      macOS 10.11：只能用 Chrome（最高 103 版）。
      装好 Chrome 后再打开本程序，它会自动用 Chrome 的独立窗口打开。
      如果官网的新版浏览器提示装不上，说明系统太旧，建议先升级系统，或者在其他设备上用网页版。
  ● macOS 10.10 及更早：不支持，请升级系统或换一台电脑。

【安卓手机】
  安卓版用的是手机系统自带的「网页组件」（Android System WebView）。
  如果打开应用后显示「手机的网页组件（WebView）版本太旧」：
    1. 打开手机自带的应用商店（华为应用市场、小米应用商店、OPPO 软件商店、
       vivo 应用商店、Google Play 等）。
    2. 搜索「Android System WebView」并更新。有的手机叫「系统 WebView」、
       「Chrome」或「浏览器内核」。
    3. 更新后重新打开本应用。
  最低要求：WebView 69（2018 年的版本）。Android 7 及以上的手机一般早已自动更新，很少遇到。
  暂时无法更新：改用网页版或电脑版。

七、常见问题
--------------------------------------------------------------

问：我的文件会上传到网上吗？
答：不会。桌面版和安卓版完全不联网（安卓版连联网权限都没有）；
    网页版也只是在你的浏览器里处理，不会把文件发出去。

问：生成的文件在哪里？
答：在电脑的「下载」文件夹（也就是浏览器设置的下载位置）。
    手机上在「下载」（Download）文件夹，可以在「文件管理」里找到，也可以在 WPS 里打开。

问：需要联网吗？
答：苹果电脑版、Windows 版和安卓版装好后完全离线可用。网页版打开页面时需要联网。

问：打开后一直显示「正在加载」或者一片空白？
答：多半是浏览器太旧，按第六部分更新浏览器。苹果电脑也可以换一个浏览器，
    打开「直接用浏览器打开.html」。

问：第三步识别得不对怎么办？
答：直接在第三步改成正确的内容，再点生成。

问：网页版、苹果电脑版、Windows 版、安卓版有什么区别？
答：用的是同一套排版引擎，生成的文件完全一样，只是打开方式不同。

问：怎么确认下载的文件没有被改过？（可选，一般不用管）
答：下载页里的 SHA256SUMS.txt 列出了三个安装包的校验值，可以对照核对。
